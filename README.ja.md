# Doki Doki Tri-Line Quest (DDTLQ) — 日本語

## 日本語化パッチの導入手順

### Windows版
1. DDTLQ 2.01.04 Betaの互換性があるWindows版を自分で用意してください。
2. `WindowsPatch.bat` を実行します。
3. 言語選択画面で `7 日本語` を選び、Enterキーを押します。
4. 自分で用意したWindows版のオリジナルゲームフォルダーを指定してください。
5. 処理が完了すると、`output` フォルダーに日本語化済みの新しいWindows版が生成されます。
6. `output` 内の新しいゲームを起動してください。元のゲームファイルは変更されず、そのまま残ります。

### Android版
1. DDTLQ 2.01.04 Betaに対応するWindows版のオリジナルゲームを自分で用意してください。
2. `Build-APK.bat` を実行します。
3. 言語選択画面で `7 日本語` を選び、Enterキーを押します。
4. 自分で用意したWindows版のオリジナルゲームフォルダーを指定してください。
5. 処理が完了すると、`output` フォルダーに署名済みAPKが生成されます。
6. APKをAndroid端末に転送し、インストールしてください。対応環境はAndroid 7以降、ARM64です。

### 注意事項
- 元のWindows版ゲームファイルは変更・削除されません。
- 既存のAndroid版ゲームやAndroid用の原本ファイルを用意する必要はありません。
- Windows版・Android版ともに、自分が所有する対応バージョンのゲームデータが必要です。
- 公開配布物に含まれるのは日本語化パッチと関連ツールのみです。ゲーム本体や完全なゲームAPKは配布されません。
