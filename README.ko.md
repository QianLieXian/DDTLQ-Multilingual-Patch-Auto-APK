# Doki Doki Tri-Line Quest (DDTLQ) — 한국어

## Windows
1. 패치 압축을 모두 풀고, 직접 보유한 호환 **DDTLQ 2.01.04 Beta Windows 원본**을 준비하세요.
2. `WindowsPatch.bat`을 실행하고 **9 — 한국어**를 선택한 뒤 **Enter**를 누르세요.
3. 원본 게임 폴더를 지정하세요. `output`에 생성된 새 복사본으로 실행하세요. 원본 파일은 유지됩니다.

## Android
1. Windows에서 `Build-APK.bat`을 실행하고 **9 — 한국어**를 선택한 뒤 **Enter**를 누르세요.
2. 같은 Windows 원본 게임 폴더를 지정하세요. 기존 Android APK는 필요하지 않습니다.
3. 도구 준비와 빌드가 끝나면 `output`의 서명된 APK를 휴대폰에 옮겨 설치하세요. **Android 7 이상, ARM64** 기기가 필요합니다.

공개 배포에는 패치와 도구만 포함됩니다. 플레이어가 호환 원본 게임을 직접 준비해야 합니다.

화면을 누르면 클릭하며, 누른 채 움직이면 드래그합니다. L/R로 마우스 왼쪽/오른쪽 버튼을 선택합니다. 보통은 L을 사용하세요. 위쪽 도우미 버튼으로 메뉴를 엽니다. 메뉴 항목 위로 드래그하기만 해서는 실행되지 않습니다.

## Xbox

Xbox 컨트롤러를 기본 지원합니다. 왼쪽 스틱(LS)이나 방향 패드로 이동하고, A로 확인·대화, B로 뒤로 가기, Start로 일시정지를 합니다. Y 또는 View로 도우미를 엽니다. 오른쪽 스틱(RS)은 가상 커서를 움직입니다. RT 또는 X는 마우스 왼쪽 클릭이며, 누른 채 이동하면 드래그합니다. LT는 오른쪽 클릭입니다. LB를 누르면 정밀하게, RB를 누르면 빠르게 커서를 움직일 수 있습니다. USB나 블루투스로 연결해 운영체제가 인식하면 바로 사용할 수 있으며, 별도 버튼 매핑 프로그램은 필요하지 않습니다.

연결하거나 게임으로 돌아온 직후에는 버튼을 놓고 스틱을 중앙으로 되돌린 다음 조작하세요.
