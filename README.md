# DDTLQ 2.01.04 简体中文补丁

适用于《Doki Doki Tri-Line Quest》2.01.04 Beta。包含按语境翻译并校对的文本、中文字体、可选助手和本地安卓制作工具。仅发布补丁，不含原游戏、音频、CG 或完整 APK。

从 [Releases](https://github.com/QianLieXian/DDTLQ-Chinese-Patch/releases) 下载补丁，解压到原 Windows 游戏目录。

- Windows：双击「一键汉化Windows.bat」，运行 `output/Windows-…` 中的游戏。
- 安卓：双击「一键制作安卓APK.bat」，使用自己的 Windows 原文件生成 APK，无需原版安卓包；首次需联网下载工具，成品在 `output/Android-PC-…`。
- 触控：左摇杆移动，右侧确认/返回，下方暂停，上方中央「助手」打开菜单。菜单可点选，也可用方向、确认、返回操作。
- 助手：F5 全图鉴、F6 全画廊、F7 弧币、F8 回血回蓝、F9 菜单、F10 原版调试、F11 生成资源副本、F12 读取副本。

图鉴和画廊为独立显示开关，不修改剧情击败记录。资源副本保留当前剧情，提供 999999 弧币；不会再强制把全部任务设为完成。

附带的是**可继续剧情的城镇辅助档，不是全流程通关档**。Windows 双击「导入城镇辅助存档.bat」会先备份旧档，再导入并开启图鉴/画廊。安卓从助手读取副本；启动页「存档与设置」可管理自己的存档。旧版本生成的“全部末阶段、关卡全零”异常档会在读取时先备份，再恢复城镇剧情状态；真实通关进度不会按此规则处理。

r3 修复装备名为 0、助手误触/坐标问题、读档后菜单挡住交互、图鉴末页缺项。已通过同运行组件的剧情推进、地图进战斗、旧生成档迁移等检查；**安卓真机触控和完整流程尚未验证**，仍为移植测试版。原作也尚未完结。
