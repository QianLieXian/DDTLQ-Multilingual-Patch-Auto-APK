# DDTLQ 2.01.04 简体中文补丁

[下载最新补丁](https://github.com/QianLieXian/DDTLQ-Chinese-Patch/releases/latest)

适用于《Doki Doki Tri-Line Quest》2.01.04 Beta。包含中文文本、像素字体、触控助手和本地安卓制作工具。只发布补丁，不含原游戏、音频、CG 或完整 APK。

解压到自己的原 Windows 游戏目录：

- Windows：双击「一键汉化Windows.bat」，运行 `output/Windows-…` 中的游戏。
- 安卓：双击「一键制作安卓APK.bat」，使用 Windows 原文件制作 APK，无需原版安卓包；首次需要联网，成品在 `output/Android-PC-…`。
- 触控：左摇杆移动，右侧确认/返回，下方暂停，上方中央「助手」打开菜单。菜单可直接点选，也可用方向、确认、返回操作。
- 助手：F5 图鉴、F6 画廊、F7 弧币、F8 回血回蓝、F9 菜单、F10 调试、F11 生成资源副本、F12 读取辅助副本。

附带可继续剧情的城镇辅助档，不是全流程通关档。安卓在游戏内选择「助手 → 读取辅助副本」，出现「已进入城镇，存档读取完成」后即可游玩。外部存档在启动页「存档与设置」导入后，到游戏标题页选择读取。

Windows 的「导入城镇辅助存档.bat」会先备份旧档。资源副本保留当前剧情，提供 999999 弧币；图鉴/画廊是独立开关，不强改剧情完成状态。旧异常生成档按严格特征识别，先备份再恢复。

r5 修复读档后未切图却提示成功：延后切换场景、恢复坐标、核验完成，并在失败时提示。r4 已收到安卓可运行反馈；r5 读档流程已通过同运行组件的回归检查，尚未逐一验证所有安卓设备和剧情分支。启动错误报告入口保留，记录不会自动上传。
