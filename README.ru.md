# Doki Doki Tri-Line Quest (DDTLQ) — Русский

## Установка

Нужна собственная совместимая Windows-версия **Doki Doki Tri-Line Quest 2.01.04 Beta**. Полностью распакуйте пакет патча.

- **Windows:** запустите `WindowsPatch.bat`, выберите **4 — Русский**, нажмите Enter и укажите папку исходной игры. Запускайте новую копию из `output`; исходные файлы сохраняются.
- **Android:** на Windows запустите `Build-APK.bat`, выберите **4 — Русский**, нажмите Enter и укажите ту же папку исходной Windows-игры. Инструменты загрузятся и проверятся автоматически. Подписанный APK появится в `output` — перенесите его на телефон с **Android 7+ и ARM64** и установите. Исходный Android APK не нужен.

Левый стик отвечает за движение; справа **ОК** (Z) и **Назад** (X), снизу **Пауза**. Верхняя кнопка **Помощь** открывает вспомогательное меню. Публичный пакет содержит только патч, переводы и инструменты, без полной игры и готового игрового APK.


Касание экрана выполняет щелчок; удерживайте палец и перемещайте его для перетаскивания. L/R выбирают левую/правую кнопку мыши; обычно используйте L. Вспомогательное меню открывается верхней кнопкой. Перетаскивание через пункт меню не подтверждает выбор.

## Xbox

Геймпад Xbox: левый стик или крестовина — движение; A — подтвердить или поговорить; B — назад; Start — пауза; Y или View — меню «Помощь». Правый стик двигает виртуальный курсор. RT или X — левая кнопка мыши; удерживайте для перетаскивания. LT — правая кнопка. Удерживайте LB для точного движения курсора, RB — для ускорения. Подключите геймпад по USB или Bluetooth: если система его распознаёт, отдельная программа для назначения кнопок не нужна.

После подключения или возвращения в игру отпустите кнопки и верните стики в центр.
